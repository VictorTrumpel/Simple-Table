# Правила проекта

- Не писать и не добавлять тесты без прямой просьбы пользователя написать тесты.
- Просьба реализовать функцию, исправить ошибку или проверить работу сама по себе не разрешает добавлять тесты.
- Для проверки изменений при необходимости использовать сборку, линтер и ручную проверку.
